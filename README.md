# 🚀 AI Career Roadmap Generator

An AI-powered career roadmap generator that creates personalized learning paths based on your career goals, current skills, and available time.

## 🔗 Live Demo
https://stunning-elf-4c9d5c.netlify.app

## ✨ Features
- 🤖 AI-generated personalized roadmaps
- 📅 Phase-by-phase learning timeline
- 🎯 Skills breakdown for each phase
- ⏱️ Time-based planning (3/6/12 months)
- 🌙 Beautiful dark theme UI
- 📱 Fully responsive design

## 🛠️ Built With
- React
- Tailwind CSS
- Vite
- OpenRouter AI API
- Meta Llama 3.1

## 🔧 Setup
1. Clone the repo
2. Run `npm install`
3. Create `.env` file with `VITE_OPENROUTER_API_KEY=your_key`
4. Run `npm run dev`
